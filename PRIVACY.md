# Privacy Policy – IP Scanner Deluxe

Last updated: November 2, 2026

IP Scanner Deluxe is a network scanner for local networks, developed by
Dominik Schmidt. This policy applies to all editions: the Microsoft Store
version and the downloads from GitHub for Windows, macOS and Linux.

*Deutsche Fassung weiter unten.*

## Summary

IP Scanner Deluxe does not collect, transmit or sell any personal data. It has
no user accounts, no telemetry, no analytics, no advertising and no crash
reporting. Everything the program finds or stores stays on your computer.

## What the program does on the network

- It sends network requests (ping, ARP, DNS, NetBIOS, LLMNR, mDNS, TCP and
  UDP probes, HTTP/HTTPS requests, SNMP if you enable it) **only to the addresses you enter
  or select** for a scan, normally devices in your local network.
- Host names are resolved through the name servers configured in your
  operating system, as for any other program.
- Wake-on-LAN, remote shutdown/restart and opening a device in an external
  program (browser, Remote Desktop, SSH, file manager) happen only when you
  start them.
- The program itself never contacts the developer or any other server on the
  internet. The GitHub link in the About dialog opens in your browser only
  when you click it.

## What is stored on your computer

Stored locally only, in the program's data folder:

- settings (for example language, theme, columns, port lists),
- favorites, comments you add to devices, and scan history used to show
  changes between scans,
- an optional MAC vendor database you import,
- a log file with technical messages (for example program start, scanned
  address ranges, errors). Passwords or other secrets are never written to
  the log.

Data folder:

- Microsoft Store version: managed by Windows inside the app's package data;
  removed when you uninstall the app.
- Windows (GitHub): `%APPDATA%\IPScannerDeluxe`, or the program folder in
  portable mode.
- macOS: `~/Library/Application Support/IPScannerDeluxe`
- Linux: `~/.local/share/ip-scanner-deluxe`

You can delete this folder at any time. Exports (CSV, HTML, JSON, XML) are
written only where you choose to save them.

## Credentials

IP Scanner Deluxe does not ask for, store or transmit passwords. Remote
shutdown and restart use the permissions of the Windows user who is signed
in.

## Children

The program does not collect data from anyone, including children.

## Changes

Changes to this policy are published in this file in the source repository
<https://github.com/ray77/ip-scanner-deluxe>, where its history is visible.

## Contact

Questions about privacy: please open an issue at
<https://github.com/ray77/ip-scanner-deluxe/issues>.

# Datenschutzerklärung – IP Scanner Deluxe

Stand: 2. November 2026

IP Scanner Deluxe ist ein Netzwerkscanner für lokale Netzwerke, entwickelt von
Dominik Schmidt. Diese Erklärung gilt für alle Ausgaben: die Microsoft-Store-
Version und die Downloads von GitHub für Windows, macOS und Linux.

## Kurzfassung

IP Scanner Deluxe erhebt, überträgt und verkauft keine personenbezogenen
Daten. Es gibt keine Benutzerkonten, keine Telemetrie, keine Analyse, keine
Werbung und keine Absturzberichte. Alles, was das Programm findet oder
speichert, bleibt auf Ihrem Computer.

## Was das Programm im Netzwerk tut

- Netzwerkanfragen (Ping, ARP, DNS, NetBIOS, LLMNR, mDNS, TCP- und
  UDP-Abfragen, HTTP/HTTPS, SNMP falls eingeschaltet) gehen **nur an die Adressen, die Sie für einen
  Scan eingeben oder auswählen**, normalerweise Geräte im eigenen Netzwerk.
- Hostnamen werden über die im Betriebssystem eingestellten Nameserver
  aufgelöst, wie bei jedem anderen Programm.
- Wake-on-LAN, Herunterfahren/Neustart entfernter Rechner und das Öffnen
  eines Geräts in einem externen Programm (Browser, Remotedesktop, SSH,
  Dateimanager) passieren nur, wenn Sie es auslösen.
- Das Programm selbst baut nie eine Verbindung zum Entwickler oder zu einem
  anderen Server im Internet auf. Der GitHub-Link im Über-Dialog öffnet sich
  nur auf Klick in Ihrem Browser.

## Was auf Ihrem Computer gespeichert wird

Nur lokal, im Datenordner des Programms:

- Einstellungen (z. B. Sprache, Design, Spalten, Portlisten),
- Favoriten, eigene Kommentare zu Geräten und ein Scanverlauf, mit dem
  Änderungen zwischen Scans angezeigt werden,
- eine optional importierte MAC-Herstellerdatenbank,
- eine Logdatei mit technischen Meldungen (z. B. Programmstart, gescannte
  Adressbereiche, Fehler). Passwörter oder andere Geheimnisse werden nie
  protokolliert.

Datenordner:

- Microsoft-Store-Version: von Windows in den Paketdaten der App verwaltet;
  wird beim Deinstallieren entfernt.
- Windows (GitHub): `%APPDATA%\IPScannerDeluxe`, im portablen Modus der
  Programmordner.
- macOS: `~/Library/Application Support/IPScannerDeluxe`
- Linux: `~/.local/share/ip-scanner-deluxe`

Sie können diesen Ordner jederzeit löschen. Exporte (CSV, HTML, JSON, XML)
landen nur dort, wo Sie sie speichern.

## Zugangsdaten

IP Scanner Deluxe fragt keine Passwörter ab, speichert und überträgt keine.
Herunterfahren und Neustart entfernter Rechner nutzen die Rechte des
angemeldeten Windows-Benutzers.

## Kinder

Das Programm erhebt von niemandem Daten, auch nicht von Kindern.

## Änderungen

Änderungen dieser Erklärung werden in dieser Datei im Quellcode-Repository
<https://github.com/ray77/ip-scanner-deluxe> veröffentlicht; dort ist der
Verlauf einsehbar.

## Kontakt

Fragen zum Datenschutz bitte als Issue unter
<https://github.com/ray77/ip-scanner-deluxe/issues>.
